# DESIGN-OF-THE-ELECTROMECHANICAL-SYSTEM-Table-Tennis-Machine
Dự án thiết kế và chế tạo máy bắn bóng bàn tự động sử dụng các cơ cấu cơ khí, động cơ DC – stepper, và vi điều khiển STM32F103C8T6. Hệ thống có khả năng điều chỉnh góc bắn, tốc độ, hướng và tạo xoáy cho bóng. Báo cáo gồm phân tích lý thuyết, mô phỏng MATLAB, thiết kế 3D trên Fusion 360 và lập trình điều khiển hoàn chỉnh.
